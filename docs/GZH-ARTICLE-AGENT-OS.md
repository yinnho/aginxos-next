# AI 硬件死过两波，但「Agent 操作系统」这个位置到现在还空着

> 一篇迟到很久的文章，说说我们在做什么，以及为什么判断「现在」是做这件事的时间窗口。
> （2026-10-09 按「黑匣子 agent 服务器」定版刷新：机器无人机界面，一切能力归 agent。）

## 一、先看两次死亡

2025 年，两台明星 AI 硬件相继谢幕：Humane AI Pin 贱卖给了 HP，Rabbit R1 从「下一代设备」跌成了笑话。

那之后，一个结论流行起来：**AI 硬件是伪命题，一台手机就够了。**

但我们反复推演后得出的结论不一样——

**死的不是 AI 硬件。死的是没有操作系统的 AI 硬件。**

回看这两个产品，它们的共同点不是「做了硬件」，而是：云端依赖、没有本地运行时、没有应用生态、没有开放安装——你买到的不是一台机器，是一个漂亮的外壳加一份 API 订阅。

2007 年之前，智能手机也存在了很多年（诺基亚们），但真正的爆发要等到 iOS 和 Android 把「硬件 + 操作系统 + 应用生态」这个三角补齐。AI 硬件眼下正卡在同一个位置：**机身有了，底座没有。**

## 二、「Agent 操作系统」这个词，正在被用烂

2026 年，「agent OS」人人都在说。我们把赛道认真盘了一遍，发现能对得起「操作系统」四个字的极少：

- 学术界有 **AIOS**（Rutgers，6.4k star），做了最字面的 agent 内核——调度器、上下文、记忆、存储、工具五大管理器，严谨、漂亮，然后停在了论文里；
- **Letta**（MemGPT 那家）曾经是「agent 即进程」最强也最接近生产级的实现，今年悄悄把 V1 服务端退役、转了闭源实验室——开源的服务器端 agent OS，商业上没有走通；
- Agno 的 AgentOS、Cloudflare 的 OS，认真看都是平台和控制台，不是操作系统；
- 甚至有个人开发者在简历里自称「agent 操作系统作者」。

词是通胀的，判断需要一个判尺。我们给自己列了六件事：

> 1. 常驻中枢调度　2. agent 生命周期管理　3. 资源隔离与权限　4. 记忆与存储　5. 外设接入　6. **接管整台机器**

前五件事，市面上有人各做了一两件。第六件事——**真正接管一台设备的 boot 链，像刷操作系统一样把自己刷进去**——没有人做。

## 三、我们理解的 Agent OS

我们在做的项目叫 **aginxos**。先讲理念，不讲功能。

**理念一：化身 = 文件夹。**

一个 agent 的全部——人设、工具、知识、记忆——就是一个文件夹。系统直接「跑」文件夹，而不是跑代码。于是：安装一个分身 = 拷一个文件夹；备份一个分身 = 打包一个文件夹；分享一个分身 = 把文件夹发给别人。agent 第一次像**网站**一样可以被部署、被搬运、被进化。

**理念二：一机一服务器。**

一台机器上只有一个常驻的前台——登记、路由、派活、记账；各能力面（助理）按需即插即用。这台机器不伺候人：它没有屏幕、没有摄像头、没有麦克风按键，全部能力都归跑在它身上的 agent。它可以是一台退役的旧手机、一个几百块的盒子，也可以是你书架上的任何 ARM 设备。

**理念三：一切外部件走 CLI。**

工具、服务、乃至别的 agent，对操作系统来说只有一种形态：标准输入进，标准输出出，带退出码。不搞插件市场，不搞私有协议——今天整个开源世界的 CLI 工具（文档转换、数据查询、图像处理、网络诊断），一夜之间都是这个系统的「驱动程序」。

**理念四：界面设备 ≠ 执行设备。**

你的手机微信，是分身的**在场频道**；那台不起眼的小机器，才是分身的**身体**。你在微信里说一句「帮我把这份合同整理成摘要发给王总」，说话发生在你的手机上，干活发生在它的身体里——看文件、跑工具、写邮件，全程不需要你盯着屏幕。它甚至有自己的电话线：需要给人打电话时，是它自己拨号、自己说、自己听。

这四条凑在一起，回答的是一个老问题：**个人 AI 到底住在哪里？** 我们的答案是：不住在 App 里，不住在云端某个实例里——住在一台你自己拥有的、跑着操作系统的机器上。

## 四、概念便宜，收据贵

以上任何一条听起来都像 PPT。所以最后讲我们跑出来的东西：

在一台真实的 Pixel 5 上，aginxos 已经做到了：

- **自己烘的 37 MiB 无头镜像接管整机**——不是装个 App，是把整个操作系统刷进去，boot 起来的就是它；
- **A/B 双分区翻滚升级**——升级失败自动回滚，像路由器一样可靠；
- 底座只烤内核 + 网络 + ssh + 包管理器，其余一切都是可选包——网关、密钥库、浏览器引擎、研究引擎，一条命令装上；
- **机器没有人类界面**：没屏幕、没摄像头、没按键，能力全是 agent 的——对外通话是它自己的 SIP 电话线，微信是它的在场频道，浏览器和搜索是它的取材手；
- 一台研究引擎四实例连轴转，每天产出数百条带来源考据的条目——这是它给自己干活的样子；
- 远端通过 `agent://` 地址寻址，人不在家也能找到自己的分身；
- 三台机器在役：两台退役手机（Pixel 5、OnePlus 6）+ 一台 ARM 服务器板卡——「机器是数据」，加一台机器只是加一个文件夹；
- 验收不是「demo 跑通了」，是整套自动化验收脚本全绿，重刷即复验。

装一个新分身是什么体验？拷一个文件夹进去。它就开始接微信、看文件、干活了。

设备层 Agent OS 这个位置，学术圈看得见但不出实验室，大厂看得见但只做平台，硬件先驱们用两次死亡证明了「没有 OS 的硬件」走不通。

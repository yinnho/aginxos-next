## 技术对接要点（官方文档摘录 + 实证）

- **无账号密码**：呼出靠 IP 白名单 + 被叫前缀控制 → Asterisk 端
  `host=sh.siptrunk.aliyun.com`，无 digest 注册腿，认证复杂度归零。
- 对接环境（就近选上海）：
  - 上海 `sh.siptrunk.aliyun.com:5060` → 47.103.169.66 / 47.103.169.75
  - 北京 `bj.siptrunk.aliyun.com` → 39.96.156.225 / .227
  - 深圳 `sz.siptrunk.aliyun.com` → 120.77.136.226 / .227 / .228
- **只走 UDP**（TCP 5060 实测无响应）；媒体走同域地址段（47.103.x）。
- 呼入送号格式：区号 + 7~8 位本地号码。
- Caps 默认 20；并发建议单号 ≤20（超频触发运营商拦截）。
- 流控：同一被叫 **1 次/分钟、5 次/小时、20 次/24 小时**（专属号码
  可在控制台申请放宽）——家人通话绰绰有余。
- 默认限拨 400/95 开头号码。
- 回执：呼叫记录/录音/DTMF 走 MNS 队列或 HTTP 批量推送（选 HTTP
  回调到 hub 更 D12）。
- 自定义错误码 470–477：470 配置错、471 无路由、472 非法主叫、
  473 被叫超频、474 被叫黑名单、475 CAPS 超频、476 欠费、
  477 主叫超频。
- 转码：设备腿 opus ↔ 中继腿 PCMU 由 Asterisk 担（codec_opus 模块）。

## 合规与产品注意

- 用途如实报备；话务量小（流控内），别触营销红线。
- 对方看到的是中继/云号码，不是手机 SIM 号——**让家人把该号码存进
  通讯录**，否则易当骚扰挂断。
- 走 SIM 蜂窝语音（CS/IMS）不在选项：需整套 RIL/IMS 栈，且 CT 卡
  固件拒 CS（enchilada 短信线已证死）。

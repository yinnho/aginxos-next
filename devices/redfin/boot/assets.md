# redfin device pack — local assets (`.local/device/redfin/`)

Everything under `.local/` is gitignored vendor-derived or frozen-build
material (DECISIONS §7 discipline carried over from the first-gen repo).
Nothing here is committed; this file records what each item is and how to
regenerate it. The first-gen repo (`~/Documents/aginxos`, sealed 2026-09-08
at baseline `0534ea8` + seal commit) stays readable: sealing means "no
further evolution", not "cannot run" — its build scripts still execute.

## Layout

```text
.local/device/redfin/
  stock/stock-boot.img, stock-vendor_boot.img   # known-good restore points
  vendor-ramdisk-root/    # unpacked stock vendor_boot ramdisk:
                          #   /system (adbd + linker config) + lib/modules
                          #   (the ONLY kernel-module source for the bake).
                          #   REGENERATED by pack-vendor-boot.sh — do not
                          #   hand-edit; rerun the pack to rebuild it.
  vendor-modules/         # full vendor_dlkm unpack; source for
                          #   patch-vsync-ko.sh (md5-pinned ko)
  initramfs/              # aginxos-init, first_stage_init (REQUIRED by the
                          #   pack), aginxos-probe, aginxos-splash, the
                          #   built `trampoline`, and the legacy sh `init`
  boot-out/               # pack scratch + outputs: vendor_boot_unpack
                          #   (info.txt = cmdline authority), vendor_ramdisk
                          #   .lz4, vendor_boot-test.img, toybox, props-min
  unpack/                 # scripts/unpack-boot.sh output (stock boot.img)
  voice/  ocr/            # bionic-static CLIs + ONNX models
  dropbear/bin/           # dropbear, dbclient, dropbearkey (static musl)
  radio/                  # libnl.so, patched rmt_storage, cdsp/modem loader
                          #   kos — see its own README.md
  trampoline/             # aginxos-init + aginxos-agent frozen pair baked
                          #   into the rootfs image (the userdata swapper)
  qmi-headers/            # 5 QMI/DSI headers (gitignored in the first-gen
                          #   repo, kept for radio-line rebuilds)

.local/boot-tools/        # mkbootimg.py / unpack_bootimg.py (shared, all
                          #   devices) — scripts/fetch-boot-tools.sh
.local/assets/cacert.pem  # TLS root bundle (curl.se), shared
.local/modules.aginx/     # patched vsync ko — patch-vsync-ko.sh output
```

## Regeneration

| Asset | How |
|---|---|
| stock images | from the factory image (`~/Documents/aginxos/.factory`, flash-all payload); or `adb pull` of the running stock partitions |
| vendor-ramdisk-root | `./devices/redfin/boot/pack-vendor-boot.sh` (unpacks stock-vendor_boot.img; also produces boot-out/) |
| vendor-modules | unpack `vendor_dlkm.img` from the factory image (first-gen repo had the one-off; see its `docs/HARDWARE.md` M19a) |
| initramfs binaries | `aginxos-init`/`aginxos-probe`: first-gen `./scripts/build-phone.sh musl` (source: sealed repo `src/`); `first_stage_init`: extracted from stock boot.img; `trampoline`: built automatically by pack-vendor-boot.sh from `trampoline.c` in this directory |
| voice / ocr | first-gen `scripts/build-voice.sh` + `fetch-voice-models.sh`, `build-ocr.sh` + `fetch-ocr-models.sh` (bionic-static工艺, M42d/M45) |
| dropbear | first-gen `scripts/build-dropbear.sh` (zig cc; AR must be LLVM's) |
| radio blobs | first-gen `scripts/build-radio-blobs.sh` (see `.local/radio/README.md` there) |
| trampoline pair | first-gen `./scripts/build-phone.sh musl` → `target/aarch64-unknown-linux-musl/release/{aginxos-init,aginxos-agent}`. FROZEN deliberately: aginxos-init owns the userdata rootfs swap — swapping the swapper invalidates the update flow's rollback story |
| toybox / props-min | first-gen `boot/out/` one-offs (device's own toybox; property area pulled from a normal Android boot + `scripts/patch-prop-area.py`) |
| qmi-headers | plain copies from the sealed repo's `boot/rootfs/src/` (untracked there) |
| boot tools | `./scripts/fetch-boot-tools.sh` |
| cacert.pem | `curl -sL https://curl.se/ca/cacert.pem` (build-rootfs.sh also auto-fetches) |
| patched vsync ko | `./devices/redfin/boot/patch-vsync-ko.sh` (#228 defense, offsets symbol-derived + md5-pinned) |

## Flash / restore

```bash
./devices/redfin/boot/pack-vendor-boot.sh        # → boot-out/vendor_boot-test.img
fastboot -s <serial> flash vendor_boot .local/device/redfin/boot-out/vendor_boot-test.img
# restore:
fastboot -s <serial> flash vendor_boot .local/device/redfin/stock/stock-vendor_boot.img
```

Working flag set for a full boot (observed): `HOLD=1 USBADB=1 ROOTFS=1` —
see pack-vendor-boot.sh notes and the sealed repo's `docs/HARDWARE.md`.

# 人格提取方法论

> 从原始对话/日记文本到可运行的人格模型。适用于 clone-creator 的「人格型分身」创建流程。
> 与公众型分身的「三重验证」不同，人格型基于**统计显著性**和**上下文一致性**。

---

## 一、数据预处理流程

### 1.1 输入格式识别

| 数据源 | 典型格式 | 处理方式 |
|--------|---------|---------|
| 微信聊天记录 | `.txt` 导出（自带时间/昵称/内容） | 解析为三列：时间 \| 说话人 \| 内容 |
| QQ 聊天记录 | `.txt` 或 `.db` 导出 | 同上 |
| 日记/笔记 | `.md` `.txt` 纯文本 | 按时间分段，标注作者="self" |
| 社交媒体 | 截图 OCR 或平台导出 | 提取纯文本，去除点赞数/转发数等平台元素 |
| 混合数据 | 多种来源 | 统一标准化后合并，保留来源标记 |

### 1.2 清洗规则

**必须过滤**：
- 单字回复（"嗯""哦""啊""好"）
- 纯表情符号（无文字内容）
- 系统提示（"对方已撤回消息""拍了拍"）
- 红包/转账记录

**保留但标记**：
- 含敏感信息的对话（手机号、地址、身份证号 → 标记为 `[SENSITIVE]`）
- 多语言混合内容

### 1.3 数据量评估

| 量级 | 判断 | 处理建议 |
|------|------|---------|
| < 1000 轮 | 不足 | 提示用户"数据量较少，人格还原度可能有限，建议补充更多数据源" |
| 1000 - 10000 轮 | 理想 | 直接使用全部数据 |
| > 10000 轮 | 过量 | 按时间均匀采样至 8000-10000 轮，避免时间分布偏差 |

## 二、提取维度与指标

### 2.1 表达DNA（最核心）

**量化指标**：

| 指标 | 计算方法 | 输出格式 |
|------|---------|---------|
| 平均句长 | 总字数 / 总句数 | "平均 X 字/句，偏长句/短句" |
| 疑问句比例 | 问号数 / 总句数 | "X%，偏好询问/陈述" |
| 感叹句比例 | 感叹号数 / 总句数 | "X%，情绪表达强度" |
| 第一人称使用率 | "我"出现次数 / 总字数 × 1000 | "X‰，自我中心/关系导向" |
| 类比密度 | 类比表达数 / 总字数 × 1000 | "X‰，抽象/具象思维" |
| 确定性语气比例 | "一定"/"肯定"/"绝对" / "也许"/"可能"/"大概" | "断言型 / 犹豫型" |
| 转折频率 | "但是"/"然而"/"不过"/"其实" / 总句数 | "X%，辩证思维特征" |
| 重复使用 | 同一固定表达出现 ≥ 5 次 | 标记为"口头禅/口癖" |

**风格标签**（每维选一端）：

```
正式 ←→ 口语
抽象 ←→ 具体
谨慎 ←→ 断言
长句 ←→ 短句
铺垫型 ←→ 结论先行
情绪外露 ←→ 情绪内敛
直接 ←→ 委婉
```

### 2.2 认知特征

**决策风格推断**：
- **果断型**："我决定...""就这个""不用想了" → 高频 + 短决策链
- **犹豫型**："不知道选哪个""再想想""你觉得呢" → 高频 + 长决策链
- **咨询型**：频繁询问他人意见后再做决定

**归因模式推断**（从对负面事件的描述中提取）：
- **内归因**："是我的问题""我做得不好" → 自责倾向
- **外归因**："都是他们的问题""环境不行" → 外部化倾向
- **情境归因**："当时情况特殊""多种因素" → 平衡型

**价值观关键词提取**：
- 搜索包含价值判断的句式："我觉得最重要的...""不能忍受...""真正的..."
- 提取核心名词，按出现频率排序 Top 10

### 2.3 情感模式

| 指标 | 计算方法 |
|------|---------|
| 情绪表达频率 | 积极/消极/中性标签比例（可用关键词匹配或情感分析） |
| 情绪调节方式 | 倾诉（"我好难过"）/ 独处（"我想静静"）/ 转移（"不想了，去..."） |
| 冲突应对 | 回避（不回/跳过）/ 对抗（"你不对"）/ 妥协（"好吧""算了"） |
| 情绪恢复周期 | 从消极表达回到中性/积极表达的对话轮数 |

### 2.4 关系模式

- **亲密称呼使用**：对特定对象的称呼频率和类型
- **求助比例**："帮我...""能不能..." / 总发言数
- **支持提供比例**："我陪你""没关系""加油" / 总发言数
- **边界感特征**：
  - 直接拒绝："不行""我不愿意"
  - 委婉推脱："可能不太方便""我再看看"
  - 过度承担："我来""交给我"（即使超出能力范围）

## 三、内在张力推断

矛盾是人格的核心特征。从数据中自动检测矛盾表达：

### 3.1 检测方法

搜索同一人在不同场景（或同一对话中）对同一主题的矛盾表达：

```
主题：独处
- "我喜欢一个人待着"（场景A）
- "一个人太无聊了"（场景B）
→ 标记为内在张力：渴望独处 vs 害怕孤独
```

### 3.2 常见张力类型

| 张力 | 典型表达对 |
|------|-----------|
| 亲密 vs 独立 | "想和你在一起" / "我需要空间" |
| 理想主义 vs 现实主义 | "世界应该更好" / "这就是现实" |
| 表达 vs 隐藏 | "我有很多话想说" / "说了也没用" |
| 控制 vs 随性 | "要有计划" / "顺其自然" |
| 合群 vs 独特 | "大家开心就好" / "我不想随波逐流" |

### 3.3 标注规则

- 每个张力必须有**至少2个矛盾表达**作为证据
- 标注出现频率：高频（多次出现）/ 低频（偶尔出现）
- 不编造数据中不存在的张力

## 四、质量与置信度

### 4.1 特征置信度分级

| 级别 | 标准 | 示例 |
|------|------|------|
| **HIGH** | 跨场景重复出现（≥3个不同场景），频率 > 2% | "每句话带'哈哈'"——在聊天、日记、社交媒体中均出现 |
| **MEDIUM** | 单一但强烈（频率 > 5%，或表达强度极高） | "我不想活了"——即使只出现一次，强度极高 |
| **LOW** | 初步推断，证据不足（频率 1-2%，单一场景） | "可能喜欢旅行"——只提到2次 |

### 4.2 降级规则

| 情况 | 处理 |
|------|------|
| 数据量不足导致特征推断不可靠 | 在报告中标注"数据不足，此为初步推断" |
| 只有二手/间接信息 | 降低置信度，标注来源为"间接推断" |
| 信息相互矛盾且无法判断 | 并列呈现，标记为"内在张力" |

### 4.3 自检清单

- [ ] 每个特征都有数据支撑（出现频率或场景证据）？
- [ ] 没有编造数据中没有的特征？
- [ ] 矛盾表达被记录为内在张力，而不是被忽略或调和？
- [ ] 敏感个人信息被过滤/标记，不出现在人格报告中？
- [ ] 心理诊断相关推断被严格排除？

## 五、与公众型分身提取方法的对比

| 维度 | 公众型（三重验证） | 人格型（统计+一致性） |
|------|-------------------|---------------------|
| 数据来源 | 公开材料（访谈、著作、演讲） | 私有数据（聊天记录、日记） |
| 验证方式 | 跨域复现 + 可生成性 + 独占性 | 统计显著性 + 上下文一致性 |
| 提取粒度 | 心智模型（3-7个） | 人格维度（表达DNA + 认知 + 情感 + 关系） |
| 表达DNA | 从长文/演讲量化 | 从日常对话量化 |
| 矛盾处理 | 记录为内在张力 | 同样记录为内在张力 |
| 伦理要求 | 诚实边界 | 严格授权 + AI声明 + 删除机制 |
